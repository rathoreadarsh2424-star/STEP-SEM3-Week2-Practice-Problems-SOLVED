# STEP-SEM3 Week 2 Practice Problems — Solved

Solutions for the five Day 2 Live-Coding problems in `STEP-SEM3-Week2-Practice Problems.pdf`.

1. **Vowel & Consonant Counter** — uses `charAt()` and loops; ignores spaces.
2. **CSV Student Record Parser** — uses `split(",")`, validates exactly three fields, prints the formatted record.
3. **File Extension Validator** — uses `lastIndexOf()`, `substring()`, and case-insensitive extension checks.
4. **Masked Phone Number Formatter** — validates ten numeric digits and builds `XXXXXX-1234` with `StringBuilder`.
5. **Bank Transaction Reference Generator & Validator** — trims input, uppercases only the first three characters, validates letters/digits without regex, and formats the date and sequence.

## Compile and run
Use Java 8 or later. From the `src` folder, compile and run each file separately. Example:

```bash
javac Problem1VowelConsonantCounter.java
java Problem1VowelConsonantCounter
```
